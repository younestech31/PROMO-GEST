`2026-11-28T01:14:39.297Z`. يعرض ثلاث أوراق: المرجع الوطني 1541، الولايات 69،

في هذه الشريحة. الخطوة التالية المحددة: إتاحة حزمة التصدير المعتمدة مع manifest/hash

## النتيجة التنفيذية المحددة

1. تسليم PR303 لا يساوي إغلاق P1-06. التغيير الحالي يسد فجوة اختبار الموجّه الفعلي
   ويصحح قراءة الاعتماد الإداري؛ لا تغيير صلاحيات أو بيانات أو API أو schema.
2. لا نطوّر مبدّلًا أو pagination جديدين؛ المطلوب لهما حزمة قبول محددة المصدر:
   SHA كامل، البيئة، أربع حالات لغة/جهاز، نتيجة كل معيار، صور أصلية مرتبطة ببصمات،
   نتائج keyboard/modal/dirty-switch، العيوب والقرار الصريح للمراجع.
3. لا نعيد وضع P1-01/P1-35 كعوائق اعتماد. مدخل الملف المحدد لـP1-02 منفصل عن
   الاعتماد المستوفى. لا نخترع checksum أو بيانات ولا نكتب في Sheets.
4. P1-08 وسياسة الفئات، P1-11 والبيانات/restore الفعلية، P1-14 وOrigin الحقيقي،
   P1-16/36/38 والمضيف، P1-25 والنسخ/الاستعادة، القانون ونطاق الإصدار: تبقى مستقلة.
   Phase1 قيد الإنجاز؛ لا فتح Phase2–5 ولا نسبة إنجاز مختلقة.
